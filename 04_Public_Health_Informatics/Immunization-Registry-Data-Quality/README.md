# Immunization Registry Data Quality Assessment

## Project Status
In Progress

## Overview
This project evaluates the quality of immunization registry data using a synthetic dataset designed to reflect common Immunization Information System (IIS) data-quality challenges.

The analysis focuses on identifying issues that may affect the accuracy, completeness, and usability of immunization data for public health surveillance and vaccination coverage assessment.

## Objectives

This project will assess:

- Data completeness for key demographic and vaccination fields
- Validity of vaccination and reporting dates
- Duplicate vaccination records
- Timeliness of vaccination reporting
- Vaccine dose sequence consistency
- Provider-level data quality patterns
- Vaccination coverage indicators

## Tools

- Python
- pandas
- SQL
- Google Colab
- GitHub

## Data

This project uses synthetic immunization records created for educational and portfolio purposes. No confidential or personally identifiable patient information is used.

## Planned Analysis

1. Perform initial data validation and exploratory analysis
2. Measure completeness of key IIS fields
3. Identify invalid or inconsistent records
4. Detect potential duplicate vaccination events
5. Calculate vaccination reporting delays
6. Compare data-quality indicators across providers
7. Assess vaccination coverage measures
8. Summarize findings and potential IIS improvement opportunities
