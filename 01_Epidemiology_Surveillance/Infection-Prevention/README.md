# Healthcare-Associated Infection Surveillance

## Project Overview

This project demonstrates the application of epidemiologic methods to healthcare-associated infection (HAI) surveillance and infection prevention.

Using simulated hospital surveillance data, this project will evaluate infection patterns, calculate infection rates, identify potential increases in healthcare-associated infections, and develop evidence-based infection prevention recommendations.

## Objectives

- Apply healthcare-associated infection surveillance principles
- Analyze CLABSI and CAUTI surveillance data
- Calculate infection rates using device-day denominators
- Evaluate infection trends across hospital units and time
- Identify potential infection clusters
- Develop an outbreak investigation approach
- Recommend appropriate infection prevention interventions

## Topics Covered

- Central Line-Associated Bloodstream Infections (CLABSI)
- Catheter-Associated Urinary Tract Infections (CAUTI)
- Clostridioides difficile infection (CDI)
- Healthcare-associated infection surveillance
- Outbreak investigation
- Infection prevention and control
