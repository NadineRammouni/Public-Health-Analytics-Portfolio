# Processed Data

This folder contains the analytic dataset used for the initial respiratory-virus surveillance analysis.

## File

`resp_net_weekly_overall_rates_2023_2026.csv`

## Inclusion Criteria

The source RESP-NET dataset was filtered to include:

- COVID-NET, FluSurv-NET, and RSV-NET
- 2023–24, 2024–25, and 2025–26 surveillance seasons
- Week-ending-date records
- Overall age category
- All races
- All sexes
- Overall surveillance geography
- Weekly hospitalization rates
- Rates per 100,000 population
- Observed estimates only

## Purpose

This dataset supports comparison of weekly hospitalization trends across COVID-19, influenza, and RSV.
