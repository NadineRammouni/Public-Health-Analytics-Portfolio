# Raw Data

## Source

CDC Respiratory Virus Hospitalization Surveillance Network (RESP-NET), Rates and Clinical Data.

## Download Date

August 4, 2026

## Raw File

`RESP-NET_Rates_and_Clinical_Data_20260804.csv`

## Storage Note

The full raw dataset is not stored in this GitHub repository because it is large and is updated over time.

The analysis files in this repository document how the source data were filtered, cleaned, and transformed into the processed analytic dataset.

## Reproducibility

To reproduce this project:

1. Download the current RESP-NET Rates and Clinical Data CSV from CDC.
2. Save the raw file locally.
3. Run the project’s data-cleaning script.
4. Use the resulting processed dataset for analysis and visualization.
