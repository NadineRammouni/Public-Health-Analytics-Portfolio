# Multi-Pathogen Respiratory Virus Surveillance

## Project Status

In progress

## Overview

This project analyzes hospitalization trends associated with COVID-19, influenza, and respiratory syncytial virus (RSV) using publicly available CDC RESP-NET surveillance data.

The analysis is designed to demonstrate how integrated respiratory surveillance can support situational awareness, identify populations experiencing disproportionate disease burden, and inform public health preparedness.

## Public Health Questions

1. How do weekly hospitalization rates differ among COVID-19, influenza, and RSV?
2. When does each respiratory virus reach its seasonal peak?
3. Which age groups experience the highest hospitalization burden?
4. Are there meaningful differences by race, ethnicity, sex, season, or surveillance site?
5. How can multiple surveillance indicators be summarized for public health decision-makers?

## Data Source

CDC Respiratory Virus Hospitalization Surveillance Network (RESP-NET).
